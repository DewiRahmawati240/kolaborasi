Penerapan Sistem Persamaan Linear Dua Variabel (SPLDV)

Apa Itu SPLDV?

SPLDV adalah sistem persamaan yang terdiri dari dua persamaan linear dengan dua variabel yang berbeda. Dalam proyek ini, SPLDV digunakan untuk menentukan harga produk daur ulang.

Contoh bentuk umum:

ax + by = c
px + qy = r

Penyelesaian SPLDV dapat dilakukan dengan metode eliminasi dan substitusi.

Analisis SPLDV Green Art

Lihat detail

Permisalan

x = Harga Tas
y = Harga Lampu

Diketahui

2x + y = 250.000
3x + 2y = 420.000

Langkah 1 - Eliminasi y

2x + y = 250.000 | × 2
4x + 2y = 500.000

3x + 2y = 420.000 | × 1
3x + 2y = 420.000

4x + 2y = 500.000
3x + 2y = 420.000
-------------------- -
x = 80.000

Langkah 2 - Substitusi

Masukkan nilai x ke persamaan pertama:

2(80.000) + y = 250.000
160.000 + y = 250.000
y = 90.000

Hasil Akhir:

Harga Tas = Rp80.000
Harga Lampu = Rp90.000

Analisis SPLDV Speaker dan Motherboard Clock

Lihat detail

Permisalan

x = Harga 1 Speaker
y = Harga 1 Motherboard Clock

Diketahui

Paket A: 2x + y = 420.000
Paket B: x + 2y = 390.000

Langkah 1 - Eliminasi x

2x + y = 420.000
x + 2y = 390.000 | × 2
2x + 4y = 780.000

2x + 4y = 780.000
2x + y = 420.000
-------------------- -
3y = 360.000
y = 120.000

Langkah 2 - Substitusi

Masukkan nilai y ke persamaan pertama:

2x + 120.000 = 420.000
2x = 300.000
x = 150.000

Hasil Akhir:

Harga 1 Speaker = Rp150.000
Harga 1 Motherboard Clock = Rp120.000
